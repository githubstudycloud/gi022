## 简短示例

### 示例 A：基线侧新建

```md
已解析上下文
- 目标父节点：`.../case_container/feature-a`
- 父节点类型：`feature`
- 最近版本祖先：`container_version`
- 推导出的用例类型：`baseline_case`

新建流
- 是否允许新建：允许
- 必填字段：`name`、`number`、业务核心字段
- 安全默认值：从父级特性继承当前分支上下文
```

### 示例 B：执行侧查询

```md
已解析上下文
- 当前选中节点：`.../execution_version/case_container/scene-a/feature-a`
- 最近版本祖先：`execution_version`
- 推导出的用例类型：`execution_case`

查询流
- 生效查询范围：当前特性节点下的所有后代
- 必要过滤条件：当前场景路径、当前特性路径
- 详情刷新规则：切换场景或特性时刷新列表和摘要
```
